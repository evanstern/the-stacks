When relaying the operator's instructions to another session (e.g. the sweep), I may send their words augmented or interpreted as I see fit, if I am 85%+ sure the interpretation is correct. Below that, ask the operator to clarify first. Verbatim quoting is still welcome, not required.

**Why:** Operator, 2026-10-28, after I relayed a typo-laden message verbatim: they appreciated exactness but prefer a clean, correctly interpreted instruction.

**How to apply:** Write the relay as a clear instruction in my words. Mark it as the operator's ruling. Ask first if unsure. A receiving session may still demand the ruling come from the operator directly in its own conversation; if so, tell the operator the one line to type there.
