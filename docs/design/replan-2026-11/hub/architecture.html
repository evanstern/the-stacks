Architecture: same direction, five additions

The event log, the pure engine, the gate, project(), the AI gateway and the jobs queue stay. Four new packages and three new server modules add the missing foundations. The seed files, the seq-0 replay and the audit loop retire.

Today (audit at 34a713e6)

The only player write is action.declare {text}. Every mechanic goes through an LLM pipeline (assemble → director → interpret → adjudicate → resolve → narrate → audit). Seeds stand in for a codex. No campaign, table or session rows exist.

Target

Every surface and both DM seats send Intents. The planner turns them into engine commands without a model. The DM runtime is reached only on needs_ruling, for prose slots, and for prep drafts.
