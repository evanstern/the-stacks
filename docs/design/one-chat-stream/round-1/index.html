TASK-0188 · One chat stream · round 1

Axis: who decides that a line is a deed? Source: alpha run 3, finding 2. Each option mocks the same 10 states with the same copy.

A — Every line is a move

The system decides

Thesis. Nothing a character says is ever lost to the wrong mode. The DM sees everything.

Risk. Every IC line costs a full turn, including small talk. The D19 talk path no longer runs for human posts. Small talk waits 8 s before anyone answers.

B — The DM reads the room

The DM decides

Thesis. Players just talk, like at a real table, and the DM asks "are you doing that?"

Risk. A deed waits for the 3 s quiet window plus a model call before the window starts. The chip needs a structured marker: a new event type or an additive field on narration. Both are frozen-contract amendments. A player who ignores the chip does nothing.

C — Say or Do

The player decides

Thesis. The player decides after writing, not before. The closest to today's events.

Risk. It is still a choice. Run 3 showed players default to the heavier one. Mitigation: the composer suggests Do when the line starts with "I " and Say when it starts with a quote.

Shared baseline

  • One composer with a speaker chip: Tamsin ▾ lists the viewer's characters, The party, and You (out of character). (( or /ooc flips to OOC. @ opens an autocomplete: @dm, then characters and NPCs.
  • OOC posts are talk rows, channel ooc. The DM never reads them, except @dm posts.
  • @dm: the AI DM answers once as an OOC aside from PlayerSeedView, with no state change. Under a human DM it is highlighted and nothing is generated.
  • Sign-off is a hold window: free mode 8 s. Hold (one click), Release, Retract, Amend, Go now (no other human present). Nobody commits over a Hold except the DM.
  • Turn mode: 3 s undo window, no Hold by others, talk and OOC still free.
  • The window lapse needs a new action.commit override "window": a 029 amendment in every option.
  • No modals. Chat is a view over the event log.
