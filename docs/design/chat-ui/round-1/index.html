Chat UI — Design Round 1

TASK-0028. Three directions for the operator’s chat surface, each showing the same states with the same copy so they can be compared directly. Chat and the Library area are designed together in every option.

0028 = this task · LIB = Library management card (follow-up)

  • A — Reference Desk

    Thesis: everything on one screen — a collapsible Library panel above the conversation, and a source pane pinned beside it that loads a citation’s passage right where you’re already looking.

    Risk: the two panes collapse badly on narrow screens, where the source pane becomes a bottom sheet.

  • B — Marginalia

    Thesis: one reading column with two tabs ("Ask" | "Library"); a citation unfolds like a footnote right under the paragraph that cites it, and an attach control beside the question box reaches the same upload form without leaving the conversation.

    Risk: long passages push the conversation apart.

  • C — Console

    Thesis: a dense operator console — a jobs strip always visible at the top, a Library panel for upload and the book list, and a log-style chat below with citations that open in a native dialog on top of everything.

    Risk: it reads as a tool, not a reading surface.
