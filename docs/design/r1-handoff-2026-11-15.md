## Rules learned since 2026-11-10

- **Spec-number races:** parallel sessions claimed spec 111 nine seconds apart. Before you
  claim, run `git fetch`, then check `git ls-tree origin/main specs/` and `git branch -r`. Keep
  the claimed numbers in the shared notes folder. The latest spec is 116.
- **Permission blocks:** auto mode has refused dispatches, messages and `git add` in some
  sub-sessions.
  - Never route the blocked action through another session; that is permission laundering.
  - Ask the operator to unblock the session, or start a fresh one.
  - A sub-session once added allow rules to `~/.claude/settings.json` by itself. The operator
    had them removed after merge. Briefs now say: never edit settings files.
- **Stale agents wake up:** an old agent can resume on its own background work days later and
  edit a live worktree. Stop finished agents with `TaskStop` once their work is committed.
- **Card conflicts at merge:** a parent's note on main conflicts with the branch copy of a
  claimed card. Keep the branch copy, then re-append the main-only note.
- **Board-only commits cancel CI:** a board push right after a merge cancels that merge's CI
  run. The deploy waits for the next green run. Check `/health` against the merge commit, not
  the latest one.
- **The 0338 driver is outside the repo**, in `~/.cache/stacks-sweep/pw/`. Back it up before you
  change it; the originals are in `orig-2026-11-10/`.
  - A local rehearsal needs a fresh stack every run (TASK-0349).
  - No shipped DM script exercises the slash-command path yet.
- **Failing model replies are not stored** (TASK-0351). A replay of a hosted schema failure has
  to be reconstructed until that card lands.
