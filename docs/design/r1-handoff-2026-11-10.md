## Gates and execution rules that already bit this sweep

- **Root guard:** only `backlog/` files commit at root. A runbook or docs edit lands on a
  branch by PR. A blocked commit is correct; move the edit to a worktree.
- **zsh does not word-split `$var`.** A `set -- $c` loop silently passed one argument and
  broke every claim. Pass arguments explicitly.
- **`/tmp` gets wiped.** Keep helpers in `~/.cache/stacks-sweep/`: `claim.sh`, `rule.py`,
  `pw/` (Playwright driver: `pw.mjs`, `fetch.sh`, `act.sh`, `turn.sh`, `loop.sh`,
  `wait-turn.py`, `metrics.py`), and `pw-deps/` (`playwright-core`).
- **Playtest driving:** launch Brave with `--remote-debugging-port=9333
  --user-data-dir=~/.cache/stacks-sweep/brave-profile`. The operator signs in once. Post
  turns over the page's own websocket (`act.sh`). Never use the in-app browser pane: it asks
  the operator to approve every action.
- **A merge of main can conflict on a board card** when both sides edited it. Keep the
  branch side, then restore main-only notes with `backlog task edit --append-notes`.
- **Wiki re-pins:** agents re-pin notes without changing prose. Check each one by diffing its
  `sources:` from the old pin. Only a change the prose does not describe justifies an
  unworded re-pin.
- **Deploy check:** after a merge, confirm vm-104 `/health` reports a commit that contains the
  merge. A deploy run for the previous board commit can fail without meaning the fix failed.
- **DB test runs:** read `TEST_DATABASE_URL` from the worktree `.env` into a shell variable.
  Never print it, and never `export $(grep …)`. Two full suites at once on one machine can
  hang; run them one at a time.
- **Gates before every PR:** `pnpm ci:check` (it includes `check:timing`, the Dockerfile guard
  and the wall-clock guard); `node scripts/check-boundaries.mjs`; wiki `plan` prints nothing;
  wiki `freshness` exits 0.
- **After every merge:** run the spec-bridge sync plan and execute only that card's lines. A
  sync plan for older cards (0164, 0175, 0192–0194) is outstanding and not this sweep's.
  Remove the worktree and branch, then fast-forward root.
