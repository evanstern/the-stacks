# Brief and Assumptions

## Branch question

How does a DM decide what the dice decide versus what the player decides, and how is each narrated?

- Every divergence between DMG 2014 and SRD 5.2.1 that the book pass listed is flagged where it applies, with the label Edition divergence.

## Assumptions

- Dice decide when the rules or the DM call for a roll. The player decides what the character attempts, says and chooses. This note set describes how sources draw that line; it does not rule on where the line belongs.
- The word DM and the word GM name the same role. SRD 5.2.1 and the web sources use GM. DMG 2014 uses DM. Notes use DM except inside SRD and web citations of the source's own term.
- Book content comes from the operator's local extracts, read by heading path. Pages and numbering for books are not cited.
- SRD page numbers equal PDF page numbers (the printed page equals the PDF page).
- The project inventory (A3) is taken at the commit pin stated in [[The-Stacks-Resolution-Today]].
- Sections of the sources not read are listed in [[_grounding]]. A claim absent from a note may be absent only because that section was not read.
