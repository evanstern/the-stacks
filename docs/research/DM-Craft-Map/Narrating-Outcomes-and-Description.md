# Narrating Outcomes and Description

_How the sources treat putting results and scenes into words: describing success and failure, describing places and events, and narrating combat. Neutral and descriptive: this note lists what the gathered sources cover. It states no verdicts._

## Tags in this area

- `success-failure-narration` — describing the result of a success or failure
- `description-narration` — scene description and narrated delivery
- `combat-narration` — describing combat

Tags were assigned by the gather passes. One entry can carry several tags and can appear in several craft notes.
