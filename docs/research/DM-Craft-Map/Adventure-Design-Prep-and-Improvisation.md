# Adventure Design, Prep and Improvisation

_How the sources treat structuring adventures, preparing for sessions, and improvising at the table. Neutral and descriptive: this note lists what the gathered sources cover. It states no verdicts._

### Dungeon Master's Guide (DMG 2014, 5th Edition 2014)

- DMG 2014 › Ch 3 Creating Adventures › Elements of a Great Adventure — Names the ingredients of a strong adventure: a credible threat, familiar tropes with twists, focus on the present, meaningful hero choices, content for each player type, surprises, and useful maps. _[adventure-design, player-agency, players-and-expectations]_
- DMG 2014 › Ch 3 Creating Adventures › Published Adventures — Notes when to lean on a published module and how to adapt it to the group. _[adventure-design]_
- DMG 2014 › Ch 3 Creating Adventures › Adventure Structure — Frames an adventure as beginning (a hook), middle (choices with consequences), and ending (a climax the players shape). _[adventure-design, pacing]_
- DMG 2014 › Ch 3 Creating Adventures › Adventure Structure › Beginning — Teaches writing a hook that gives characters a compelling personal reason to engage. _[adventure-design]_
- DMG 2014 › Ch 3 Creating Adventures › Adventure Structure › Middle — Teaches letting each challenge present real choices that visibly affect where the story ends up. _[adventure-design, player-agency]_
- DMG 2014 › Ch 3 Creating Adventures › Adventure Structure › Ending — Teaches building tension toward a climax that depends on prior successes and failures and resolves the threat. _[adventure-design, pacing]_

- DMG 2014 › Ch 3 Creating Adventures › Adventure Types › Location-Based Adventures — Step-by-step recipe: set party goals, pick key NPCs, detail the place, craft an introduction and a climax, then plan encounters; supported by roll tables for goals, villains, allies, patrons. _[adventure-design, npcs, encounter-design]_
- DMG 2014 › Ch 3 Creating Adventures › Adventure Types › Event-Based Adventures — Recipe built around a villain's timeline: choose the villain, script their actions, set party goals, anticipate the villain's reactions to interference, and detail only the places that matter. _[adventure-design, npcs, player-agency]_

## Where sources visibly disagree

- Prep volume. Sly Flourish advises preparing only for the next session and building situations with several solutions; the Alexandrian node-based and key-based design titles point toward more structured scenario prep. Both oppose scripted plots. The gatherer marked this low confidence because it rests on titles and summaries. (https://slyflourish.com/top_advice.html; https://thealexandrian.net/wordpress/7949/roleplaying-games/node-based-scenario-design-part-1-the-plotted-approach)
