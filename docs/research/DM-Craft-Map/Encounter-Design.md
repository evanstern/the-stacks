## Entries by source

### Dungeon Master's Guide (DMG 2014, 5th Edition 2014)

- DMG 2014 › Ch 3 Creating Adventures › Adventure Types › Location-Based Adventures — Step-by-step recipe: set party goals, pick key NPCs, detail the place, craft an introduction and a climax, then plan encounters; supported by roll tables for goals, villains, allies, patrons. _[adventure-design, npcs, encounter-design]_
- DMG 2014 › Ch 3 Creating Adventures › Creating Encounters — States that an encounter should be fun for players and light to run, and introduces the section's tools. _[encounter-design]_
- DMG 2014 › Ch 3 Creating Adventures › Creating Encounters › Character Objectives — Teaches giving each encounter a clear, visible goal so players are not frustrated, with a list of sample objectives. _[encounter-design, player-agency]_
- DMG 2014 › Ch 3 Creating Adventures › Creating Encounters › Creating a Combat Encounter — Method for rating combat difficulty (easy to deadly) with party XP thresholds and monster-count multipliers. _[encounter-design, combat-running]_
- DMG 2014 › Ch 3 Creating Adventures › Creating Encounters › Creating a Combat Encounter › Evaluating Encounter Difficulty — Walk-through for summing monster XP, applying a group multiplier, and comparing to the party's thresholds. _[encounter-design]_
- DMG 2014 › Ch 3 Creating Adventures › Creating Encounters › Creating a Combat Encounter › Party Size — Adjusts the multiplier for parties smaller or larger than the baseline. _[encounter-design]_
- DMG 2014 › Ch 3 Creating Adventures › Creating Encounters › Creating a Combat Encounter › Multipart Encounters — Treats a fight that arrives in waves as separate encounters for budgeting. _[encounter-design]_
- DMG 2014 › Ch 3 Creating Adventures › Creating Encounters › Creating a Combat Encounter › Building Encounters on a Budget — Reverses the method: start from a target difficulty and spend an XP budget on monsters. _[encounter-design]_
- DMG 2014 › Ch 3 Creating Adventures › Creating Encounters › Creating a Combat Encounter › The Adventuring Day — Gives a per-character daily XP budget and expected number of fights, with guidance on short rests. _[encounter-design, pacing, time-tracking]_
- DMG 2014 › Ch 3 Creating Adventures › Creating Encounters › Modifying Encounter Difficulty — Shows how location, surprise, and situation can shift difficulty a step up or down. _[encounter-design]_
- DMG 2014 › Ch 3 Creating Adventures › Creating Encounters › Fun Combat Encounters — Lists features that add suspense: risky terrain, hazards, shifting battlefields, and more than a plain slugfest. _[encounter-design, combat-running]_
- DMG 2014 › Ch 3 Creating Adventures › Random Encounters — Teaches placing, timing, and building tables for random encounters so they support the intended session narrative. _[encounter-design, exploration, improvisation]_
- DMG 2014 › Ch 3 Creating Adventures › Random Encounters › Triggering Random Encounters — Advises choosing placement thoughtfully so random events build on the session instead of competing with it. _[encounter-design, pacing]_
- DMG 2014 › Ch 3 Creating Adventures › Random Encounters › Checking for Random Encounters — Describes when to check (per hour, per several hours, per day and rest) or simply decide. _[encounter-design, time-tracking]_
- DMG 2014 › Ch 3 Creating Adventures › Random Encounters › Creating Random Encounter Tables — Shows how to build a table with weighted likelihoods and mixed dice. _[encounter-design]_
- DMG 2014 › Ch 3 Creating Adventures › Random Encounters › Random Encounter Challenge — Warns that random fights need not be level-matched but should not be used to wipe a party. _[encounter-design, combat-running]_
- DMG 2014 › Ch 5 Adventure Environments › Dungeons › Dungeon Inhabitants — Covers factions, ecology, and scaling encounter difficulty depth by depth. _[adventure-design, encounter-design]_
- DMG 2014 › Ch 5 Adventure Environments › Urban Encounters — Covers law and order, trials, sentences, and random urban events. _[social-interaction, encounter-design]_
- DMG 2014 › Ch 8 Running the Game › Chases — Turns chases into a structured scene with initiative, limited dashing, complications, and an escape check. _[encounter-design, pacing, combat-running]_
- DMG 2014 › Ch 8 Running the Game › Chases › Beginning a Chase — Setting participants and starting conditions. _[encounter-design]_
- DMG 2014 › Ch 8 Running the Game › Chases › Ending a Chase — Conditions for ending and the quarry's escape check. _[encounter-design]_
- DMG 2014 › Ch 8 Running the Game › Chases › Chase Complications — Random tables of obstacles for urban and wilderness chases, plus advice on making your own, splitting up, mapping, and role reversal. _[encounter-design, improvisation]_
- DMG 2014 › Ch 9 Dungeon Master's Workshop › Creating a Monster — Teaches modifying or building monsters, from quick stats to a full stat block, using a challenge rating table. _[encounter-design, adventure-design]_
- DMG 2014 › Ch 9 Dungeon Master's Workshop › Creating a Monster › Modifying a Monster — Swap weapons or add traits instead of starting over. _[encounter-design]_
- DMG 2014 › Ch 9 Dungeon Master's Workshop › Creating a Monster › Creating Quick Monster Stats — Four-step method keyed to expected challenge rating. _[encounter-design]_
- DMG 2014 › Ch 9 Dungeon Master's Workshop › Creating a Monster › Creating a Monster Stat Block — Twenty-step procedure covering name, size, type, abilities, defenses, offense, and final rating. _[encounter-design]_
- DMG 2014 › Ch 9 Dungeon Master's Workshop › Creating a Monster › Monsters with Classes — Giving class levels to monsters. _[npcs, encounter-design]_
- DMG 2014 › Appendix A Random Dungeons › Random Dungeons › Stocking a Dungeon — Tables for chamber purpose, state, contents, and monster motivation to fill a dungeon quickly. _[improvisation, encounter-design, adventure-design]_

### Xanathar's Guide to Everything (XGtE, 2017)

- XGtE › Dungeon Master's Tools › Encounter Building — Alternative five-step method for balancing combat by party level and size rather than XP math. _[encounter-design]_
- XGtE › Dungeon Master's Tools › Encounter Building › Step 1: Assess the Characters — Look at party level and size first. _[encounter-design]_
- XGtE › Dungeon Master's Tools › Encounter Building › Step 2: Choose Encounter Size — Choose between a solo foe and a group. _[encounter-design]_
- XGtE › Dungeon Master's Tools › Encounter Building › Step 3: Determine Numbers and Challenge Ratings — Table lookups for solo and multi-monster ratings. _[encounter-design]_
- XGtE › Dungeon Master's Tools › Encounter Building › Step 4: Select Monsters — Pick monsters to match the ratings. _[encounter-design]_
- XGtE › Dungeon Master's Tools › Encounter Building › Step 5: Add Flavor — Teaches layering personality, relationships, terrain, traps, and off-screen events so a fight is more than numbers. _[encounter-design, npcs, description-narration]_
- XGtE › Dungeon Master's Tools › Encounter Building › Quick Matchups — Shortcuts when there is no prep time. _[encounter-design, improvisation]_
- XGtE › Dungeon Master's Tools › Random Encounters › A World of Possibilities — Builds on the core random-encounter advice: treat each result as a potential challenge, not necessarily a fight, and decide how monsters will react. _[encounter-design, improvisation, exploration]_
- XGtE › Dungeon Master's Tools › Random Encounters › Flight, or Fight, or ... ? — Reminds the DM that results can be social, avoided, or discovered and offers hooks for non-combat reactions. _[encounter-design, social-interaction, improvisation]_
- XGtE › Dungeon Master's Tools › Random Encounters › Encounter Tables by Terrain — Heading-level only. Tables for arctic, coastal, desert, forest, grassland, hill, mountain, swamp, Underdark, underwater, and urban terrain, each split by level band. _[encounter-design, exploration]_
- XGtE › Traps Revisited › Simple Traps — Frames a one-shot trap as an encounter with its own statistics, trigger, and counterplay. _[hazards-traps, encounter-design]_

### Tasha's Cauldron of Everything (TCoE, 2020)

- TCoE › Ch 4 Dungeon Master's Tools › Parleying with Monsters — Teaches resolving a monster meeting through negotiation by offering what the creature wants. _[social-interaction, npcs, encounter-design]_
