# Running Combat

_How the sources treat the procedure of running a fight: initiative, tracking, action options, adjudicating effects, and variants. Neutral and descriptive: this note lists what the gathered sources cover. It states no verdicts._

## Where sources visibly disagree

- Choosing monster targets. Sly Flourish favors open random rolls to pick which character a monster attacks; the Angry GM favors the GM deciding outcomes and consequences without fudging and is silent on targeting. The gatherer recorded this as not a direct contradiction. (https://slyflourish.com/roll_to_target.html; https://theangrygm.com/tao-of-dice/)

Edition note: the book entries describe 5th-edition text from 2014 to 2021 (DMG 2014 is the 2014 Dungeon Master's Guide). The project's rules baseline is SRD 5.2.1 (2024 rules). Divergences are flagged only where seen in the material read; see the observed list in [[Adjudication-and-Dice|Adjudication and Dice]] and the open question in [[Brief-and-Assumptions|Brief and Assumptions]].
